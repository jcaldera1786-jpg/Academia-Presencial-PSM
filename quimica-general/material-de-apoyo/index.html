🔥 Termoquímica y Termodinámica

Guía extensa para Ingeniería · Primera y Segunda Ley · Entalpía · Entropía · Ley de Hess · Aplicaciones

🌍 ¿Por qué esto es crucial para un ingeniero?
Desde motores de combustión hasta plantas de energía, pasando por baterías, refrigeración y síntesis química industrial — la termodinámica gobierna la eficiencia y viabilidad de todo proceso energético. Esta guía te dará las herramientas para calcular calor, predecir espontaneidad y optimizar reacciones.

📊 1. Termoquímica. Relación entre Calor y Reacción

Definición: La termoquímica es la parte de la termodinámica que estudia el calor intercambiado (absorbido o liberado) durante una reacción química o un cambio físico.

🔹 Clasificación de procesos según el calor

  • Reacción exotérmica: libera calor al entorno. ΔH < 0. Ej: combustión de metano, neutralización ácido-base.
  • Reacción endotérmica: absorbe calor del entorno. ΔH > 0. Ej: fotosíntesis, descomposición de carbonato de calcio.

Ejemplo cotidiano:

  • ⚡ Exotérmica: Quemar gas en una estufa (liberas calor para cocinar).
  • ❄️ Endotérmica: Las bolsas de frío instantáneo (nitrato de amonio + agua) absorben calor y bajan la temperatura.

🔹 Magnitudes clave en termoquímica

  • q = calor transferido (J o cal). Depende del camino (no es función de estado).
  • w = trabajo realizado (J). En química, w = –P·ΔV (trabajo presión-volumen).
  • ΔU = cambio de energía interna (ΔU = q + w). Función de estado.

⚡ 2. Primera Ley de la Termodinámica

ΔU = q + w

Enunciado: "La energía no se crea ni se destruye, solo se transforma". El cambio en la energía interna de un sistema es igual a la suma del calor y el trabajo intercambiados con el entorno.

Convenio de signos (importante para ingeniería):

  • q > 0 → el sistema absorbe calor (endotérmico).
  • q < 0 → el sistema libera calor (exotérmico).
  • w > 0 → el sistema recibe trabajo (compresión).
  • w < 0 → el sistema realiza trabajo (expansión).

Para procesos a volumen constante: ΔV = 0 → w = 0 → ΔU = qv (calor medido en bomba calorimétrica).

🔹 Aplicación ingenieril: Calorimetría

Los ingenieros usan calorímetros para medir el poder calórico de combustibles, alimentos o reacciones industriales.

Ejemplo resuelto: Un sistema absorbe 1500 J de calor y realiza un trabajo de 600 J sobre el entorno. Calcula ΔU.

Solución:

q = +1500 J (absorbe)    w = –600 J (realiza trabajo)
ΔU = 1500 + (–600) = +900 J

El sistema aumentó su energía interna en 900 J.

🔥 3. Concepto de Entalpía (H)

Definición: La entalpía es una función de estado que mide el contenido calórico de un sistema a presión constante.

H = U + P·V

En la práctica, la mayoría de las reacciones químicas ocurren a presión constante (atmósfera abierta). Por eso usamos ΔH (cambio de entalpía) en lugar de ΔU.

Relación clave:

ΔH = ΔU + P·ΔV   →   ΔH = qp (calor a presión constante)

Por eso, en química general casi siempre trabajamos con ΔH.

🔹 Entalpías de reacción estándar (ΔH°rxn)

  • Entalpía de formación estándar (ΔHf°): calor asociado a la formación de 1 mol de compuesto a partir de sus elementos en su estado estándar (25°C, 1 atm).
  • ΔHf° para elementos en su forma más estable es cero (ej: O₂, H₂, C grafito).

Fórmula para calcular ΔH° de reacción:

ΔH°rxn = Σ n·ΔHf°(productos) – Σ m·ΔHf°(reactivos)

donde n y m son los coeficientes estequiométricos.

🧩 4. Ley de Hess

Enunciado: "El cambio de entalpía de una reacción global es la suma algebraica de los cambios de entalpía de las reacciones parciales en las que se puede descomponer, siempre que el estado inicial y final sean los mismos."

🔑 Implicación práctica: Podemos calcular ΔH para reacciones que no se pueden medir directamente en el laboratorio, combinando reacciones conocidas.

Ejemplo resuelto (Ley de Hess):

Calcular ΔH° para la reacción:
C(grafito) + ½ O₂(g) → CO(g)

Datos conocidos:

  1. C(grafito) + O₂(g) → CO₂(g)   ΔH = –393.5 kJ
  2. CO(g) + ½ O₂(g) → CO₂(g)   ΔH = –283.0 kJ

Estrategia: Invertimos la reacción (2) y la sumamos con (1):

C(grafito) + O₂(g) → CO₂(g)   (ΔH = –393.5 kJ)
CO₂(g) → CO(g) + ½ O₂(g)   (ΔH = +283.0 kJ)  (invertida)
C(grafito) + ½ O₂(g) → CO(g)   ΔH = –110.5 kJ

La entalpía de formación del CO(g) es –110.5 kJ/mol.

🌀 5. Segunda Ley de la Termodinámica

Enunciado (Clausius): "El calor no puede fluir espontáneamente desde un cuerpo frío a uno caliente sin realizar trabajo."

Enunciado (Kelvin-Planck): "Es imposible convertir completamente el calor en trabajo sin que ocurran otros efectos."

Consecuencia fundamental para la ingeniería:

  • Ninguna máquina térmica puede tener una eficiencia del 100% (siempre hay pérdidas por fricción y calor residual).
  • Los procesos reales son irreversibles y van hacia el aumento de la entropía del universo.

🔹 La entropía como criterio de espontaneidad

Para que un proceso sea espontáneo (sin intervención externa), la entropía total (sistema + entorno) debe aumentar.

ΔSuniverso = ΔSsistema + ΔSentorno > 0

📈 6. Entropía (S) y Temperatura

Definición: La entropía es una función de estado que mide el grado de desorden o dispersión energética de un sistema. A mayor desorden, mayor entropía.

🔹 Factores que aumentan la entropía

  • Cambios de fase: Sólido → Líquido → Gas (aumenta S).
  • Aumento de temperatura: las partículas se mueven más → más microestados → aumenta S.
  • Reacciones que aumentan el número de moles gaseosos: 2H₂O₂(l) → 2H₂O(l) + O₂(g) (aumenta S por el O₂).

🔹 Relación entre entropía y temperatura (calor reversible)

ΔS = qrev / T   (para un proceso isotérmico reversible)

Para procesos a presión constante y con cambio de temperatura:

ΔS = n·Cp · ln( T2 / T1 )

Entropía estándar de reacción:

ΔS°rxn = Σ n·S°(productos) – Σ m·S°(reactivos)

Donde S° son entropías molares estándar (tablas).

⚖️ 7. Energía Libre de Gibbs (G)

Definición: Es el criterio definitivo para determinar la espontaneidad de un proceso a T y P constantes (las condiciones más comunes en ingeniería).

ΔG = ΔH – T·ΔS

Criterio de espontaneidad:

  • ΔG < 0 → Proceso espontáneo (exergónico).
  • ΔG = 0 → Equilibrio (el sistema está en su estado más estable).
  • ΔG > 0 → Proceso no espontáneo (endergónico) — requiere trabajo externo.

Ejemplo resuelto: Para una reacción con ΔH = –100 kJ y ΔS = –0.200 kJ/K, ¿es espontánea a 300 K y a 600 K?

Solución:

  • A 300 K: ΔG = –100 – 300·(–0.200) = –100 + 60 = –40 kJ → ¡Espontánea!
  • A 600 K: ΔG = –100 – 600·(–0.200) = –100 + 120 = +20 kJ → ¡No espontánea!

Conclusión: La espontaneidad depende de la temperatura. Procesos exotérmicos pero con ΔS negativo solo son espontáneos a temperaturas bajas.

🏗️ 8. Aplicaciones en Ingeniería

Área de ingeniería Aplicación directa de termodinámica
Ingeniería mecánica / térmica Motores de combustión interna (ciclo Otto, Diesel). Eficiencia limitada por la 2ª ley.
Ingeniería química Diseño de reactores: equilibrio químico (ΔG = 0) y control de temperatura para maximizar rendimiento.
Ingeniería de materiales Diagramas de fases y tratamientos térmicos (difusión controlada por entropía).
Ingeniería eléctrica / electrónica Baterías y pilas de combustible: la ΔG se convierte en trabajo eléctrico (Weléctrico = –n·F·E).
Ingeniería ambiental Evaluación de procesos de captura de CO₂, eficiencia energética y huella de carbono.

✍️ 9. Ejercicios Resueltos (paso a paso)

Ejercicio 1 – Primera Ley

Enunciado: Un gas se expande desde 2.0 L hasta 5.0 L a presión constante de 1.5 atm, absorbiendo 850 J de calor. Calcula ΔU.

Solución:

  1. Convertir trabajo: w = –P·ΔV = –1.5 atm · (5.0 – 2.0) L = –4.5 atm·L.
  2. Convertir a J: 1 atm·L = 101.325 J → w = –4.5 · 101.325 = –456 J.
  3. ΔU = q + w = 850 J + (–456 J) = +394 J.

Ejercicio 2 – Ley de Hess

Enunciado: Calcula ΔH° para 2C(grafito) + 2H₂(g) + O₂(g) → C₂H₄O₂(l) (ácido acético) usando las siguientes reacciones:

  1. C(grafito) + O₂(g) → CO₂(g)   ΔH = –393.5 kJ
  2. H₂(g) + ½O₂(g) → H₂O(l)   ΔH = –285.8 kJ
  3. C₂H₄O₂(l) + 2O₂(g) → 2CO₂(g) + 2H₂O(l)   ΔH = –871.7 kJ

Solución (estrategia): Invertir la reacción (3) y sumar 2·(1) + 2·(2) + [–(3)].

2C(grafito) + 2O₂(g) → 2CO₂(g)   ΔH = –787.0 kJ
2H₂(g) + O₂(g) → 2H₂O(l)   ΔH = –571.6 kJ
2CO₂(g) + 2H₂O(l) → C₂H₄O₂(l) + 2O₂(g)   ΔH = +871.7 kJ
2C(grafito) + 2H₂(g) + O₂(g) → C₂H₄O₂(l)   ΔH = –486.9 kJ

Ejercicio 3 – Energía Libre y Espontaneidad

Enunciado: Para la reacción N₂(g) + 3H₂(g) → 2NH₃(g), ΔH° = –92.2 kJ y ΔS° = –198.7 J/K. ¿A qué temperatura se vuelve no espontánea?

Solución:

  • La reacción es espontánea cuando ΔG < 0 → ΔH – T·ΔS < 0.
  • Despejamos T < ΔH / ΔS (cuidado con signos).
  • ΔH = –92.2 kJ = –92200 J; ΔS = –198.7 J/K.
  • T = ΔH / ΔS = (–92200) / (–198.7) = 464 K.
  • Conclusión: Por debajo de 464 K es espontánea; por encima, no (porque el término –TΔS se vuelve positivo y domina).

🧪 10. Ejercicios Propuestos (para practicar)

1. Primera Ley: Un sistema recibe 2500 J de calor y su energía interna aumenta en 1800 J. ¿Realizó o recibió trabajo? ¿De qué magnitud?

  • C₂H₄(g) + 3O₂(g) → 2CO₂(g) + 2H₂O(l)   ΔH = –1411 kJ
  • C₂H₅OH(l) + 3O₂(g) → 2CO₂(g) + 3H₂O(l)   ΔH = –1367 kJ

3. Entropía: ¿Cuál proceso tiene mayor aumento de entropía? Justifica:
a) Hielo fundiendo a 0°C   b) Agua hirviendo a 100°C   c) N₂(g) + 3H₂(g) → 2NH₃(g)

4. Gibbs: Una reacción tiene ΔH = +50 kJ y ΔS = +0.100 kJ/K. ¿A partir de qué temperatura será espontánea? Interpreta el resultado.

5. Aplicación ingenieril: Explica por qué un motor de combustión interna no puede tener una eficiencia del 100% usando la 2ª ley de la termodinámica.

🎯 Resumen para el examen de ingeniería

  • Primera Ley: ΔU = q + w → la energía se conserva. Usa ΔH = qp para reacciones a presión constante.
  • Ley de Hess: Suma algebraica de entalpías. Útil para reacciones no medibles.
  • Segunda Ley: La entropía del universo siempre aumenta. ΔSuniv > 0.
  • Gibbs: ΔG = ΔH – TΔS. Si ΔG < 0 → espontáneo. Criterio definitivo para procesos a T y P ctes.
  • Consejo ingenieril: Siempre verifica unidades (J vs kJ, atm·L vs J) y el signo de cada término.
